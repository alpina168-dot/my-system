# 仕入れ支援システム 要件定義 v1

最終更新: 2026-04-15

## 1. 目的
- 仕入れ候補の発見時間を短縮する。
- スマホで即判断できる通知と一覧を提供する。

## 2. 対象
- 監視サイト: ヤフオク / メルカリ / ラクマ / ヤフーショッピング / 楽天市場
- ブランド: CHANEL
- カテゴリ: バッグ、財布

## 3. 通知判定ルール（ユーザー合意）
以下のいずれかを満たした場合に通知対象とする。
- 利益額 >= 2 円
- 利益率 >= 30%

> 補足: 高額商品と低額商品で判断軸を変えられるよう OR 条件にする。

## 4. 仕入れ上限
- 財布: 50,000 円
- チェーンウォレット: 100,000 円
- バッグ: 300,000 円

## 5. 除外キーワード
ジャンク / 破損 / 部品取り / 訳あり / 欠損 / 欠品 / サンプル / 難あり / レプリカ / パロディー / ノベルティー / アメニティー / 鑑定前

## 6. コスト計算（暫定）
- 仕入れ送料: 1,200 円
- 販売送料: 750 円
- 販売手数料率（メルカリ想定）: 10%
- 為替・税: 国内のみ（本システム外）


## 6.1 想定売価マスタ（確定）
- 想定売価は手動算出ではなく、`data/chanel_expected_prices.tsv` のキーワード一致で決定する。
- 形式: `keyword<TAB>expected_price_jpy`
- 一致ルール（実装方針）:
  1. 商品名を正規化（全角/半角ゆれ、余分スペース除去、数字表記ゆれを吸収）
  2. マスタ内キーワードの部分一致数を評価
  3. 最長一致キーワードを優先
  4. 同点時は価格が高い方を採用
  5. 未一致時は通知しない（確定）

## 7. 通知方式
同一データ基盤を使って、2つの実行モードを用意する。
1. 即時監視モード: 定期実行で新着候補を即時 Discord 通知
2. 手動実行モード: ユーザーのボタン操作で任意タイミング実行

## 8. 出力先
- Discord（既存Webhookへ通知）
- Google スプレッドシート（候補一覧）

### 8.1 候補一覧シート列
- 商品名
- 価格
- 想定売価
- 利益
- 利益率
- URL
- 帳簿転記（チェックボックス）

### 8.2 帳簿連携
候補一覧シートの「帳簿転記」にチェックが入った行を、帳簿シートへ転記する。

### 8.3 帳簿シート列
- 購入日
- 商品名
- 仕入先情報
- 仕入れ金額
- 仕入送料
- 販売日
- 売上金額
- 販売手数料
- 販売送料
- 純利益
- 利益率
- 仕入商品URL
- リペア完了日
- ステータス（販売中 / 販売済 / 自分用）

### 8.4 帳簿シートUI要件
- 日付項目はカレンダー入力
- ステータスはプルダウン入力

## 9. 次ステップで確定が必要な項目
1. 監視間隔（例: 5分, 10分）
2. 手動実行ボタンの実装先（Web画面 or GASメニュー）
3. サイト別取得方式（公式API優先、規約順守）
4. Google認証とDiscord Webhookの安全な保管方法
5. 想定売価マスタの更新フロー（誰が・いつ・どの画面で更新するか）

## 10. コンプライアンス
- 各サイトの利用規約・API規約に従う。
- 真贋の誤認を誘発する用途は本システムの対象外とする。
- 取引履歴は法令に従って記録・保管する。


## 11. 確定事項（2026-04-15 追記）
- 想定売価マスタでキーワード未一致の出品は、Discord通知しない。
- 未一致データはシートに「未一致」として記録し、後でマスタ更新対象として確認する。


## 12. 実装決定（2026-04-15 追記）
- 監視間隔は **5分ごと** とする。
- 手動実行は当面 **Googleスプレッドシート（GASメニュー）** から起動する。
  - 補足: 将来、スマホ最適化のために専用Web画面を追加してもよい。
- サイト別取得方式は **公式API優先** とする。
  - ヤフオクは公開API終了前提のため、代替取得方式を別途検討する。
  - そのほかのサイトは公式提供状況を確認し、利用規約順守で選定する。

## 13. 用語メモ（初心者向け）
### 13.1 認証情報の保管方法とは
Google連携やDiscord通知を動かすための「秘密の鍵（トークン/Webhook URL）」を、
どこに安全に保存するかを決めること。

- NG例: コードに直接書く、シートの見えるセルに平文で書く
- 推奨例: GASのScript PropertiesやSecrets管理に保存し、権限者のみ閲覧可能にする

### 13.2 想定売価マスタ更新フローとは
`data/chanel_expected_prices.tsv` の価格表を、
「誰が」「いつ」「どこから」更新するかを決める運用ルールのこと。

- 例:
  - 誰が: あなた（管理者）
  - いつ: 週1回 + 未一致が10件たまった時
  - どこから: スプレッドシートの管理シートから更新してTSVへ反映


## 14. 運用決定（2026-04-15 追記）
- 認証情報の保存先は **GAS Script Properties** を採用する。
- 対象: Google連携に必要な設定値、Discord Webhook URL。
- ルール: コードやシートセルに秘密情報を直接書かない。
